# BusFleet — діагностична версія

У цій версії помилки MySQL повертаються у JSON із кодом і текстом помилки, а traceback пишеться в консоль Uvicorn. Додано read-only endpoint `/diagnostics/database`, який перевіряє таблиці та колонки без зміни даних.

## Запуск

1. Зупиніть старий сервер `Ctrl+C`.
2. Розпакуйте проєкт у нову папку або замініть файли `app/` та `sql/` у вашому проєкті. Не видаляйте свій `.env`; залиште власні облікові дані й звірте назви змінних із `.env`.
3. Запустіть сервер саме з кореня цієї папки:
   - `uv run uvicorn app.main:app --reload`
   - або `python -m uvicorn app.main:app --reload`
4. Відкрийте `/diagnostics/database`. Якщо `all_ok` — `false`, у `checks` буде назва таблиці або колонки, що не відповідає коду.
5. Повторіть додавання об'єкта в `/docs`. Відповідь 500 має містити `database_error`, а в терміналі буде traceback.

`sql/schemas.sql` виправлений для створення бази `bus_fleet`, але не змінює структуру вже наявних таблиць через `IF NOT EXISTS`. Не виконуйте SQL-операції видалення, щоб не втратити наявні дані.
