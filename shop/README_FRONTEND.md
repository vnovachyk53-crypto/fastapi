# Bookly frontend

## Запуск

1. Переконайся, що MySQL запущений, база `auth_demo` створена, а налаштування `.env` правильні.
2. Відкрий термінал у теці `shop`.
3. Запусти застосунок командою `uv run fastapi dev`.
4. Відкрий `http://127.0.0.1:8000`.

## Можливості

- Каталог і перегляд окремої книги доступні без авторизації.
- Реєстрація та вхід через наявні `/auth/register` і `/auth/login`.
- Після входу доступні створення (`POST /books`), редагування (`PUT /books/{id}`) та видалення (`DELETE /books/{id}`).
- Сервер перевіряє сесію для кожної CRUD-операції; приховування кнопок у браузері не є єдиним захистом.

## Важливо про збереження

У початковому навчальному проєкті книги зберігаються у Python-списку, а не в таблиці MySQL. Тому зміни працюють, поки процес сервера запущений, але зникають після його перезапуску. Для постійного збереження потрібно додати ORM-модель `Book` і перевести `book_service` на SQLAlchemy.
